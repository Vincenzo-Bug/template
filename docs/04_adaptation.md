# Adaptation Checklist

When creating a project from this template:

1. Rename the package, distribution, CLI, service identifiers, and environment
   prefix.
2. Replace this documentation with a product charter, architecture, API
   contract, threat model, and deployment runbook.
3. Define authentication, authorization, tenancy, data retention, and secrets
   management before handling user or production data.
4. Add domain entities, migration revisions, routes, and tests incrementally.
5. Review the default capability deny set before adding automation, model tools,
   or external side effects.
6. Pin operational ownership and an incident response path before production.
