# Issue tracker: Local Markdown

Issues and specs live as Markdown files under `.scratch/`.

- One feature per directory: `.scratch/<feature>/`
- Spec: `.scratch/<feature>/spec.md`
- Tickets: `.scratch/<feature>/issues/<NN>-<slug>.md`
- Triage state: a `Status:` line near the top of each ticket
- Conversation history: append under `## Comments`
